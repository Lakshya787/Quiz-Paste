# Morrow Studio

Morrow Studio is a watercolor-inspired image-creation interface prototype. Sketch a prompt, choose a mood, and explore a small local gallery of illustrated worlds.

The current image preview is a local UI demo. It does not connect to an image-generation service. Styling uses Tailwind CSS v4.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

Import this repository into Vercel. Next.js deploys with the default settings.
